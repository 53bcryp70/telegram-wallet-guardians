# Handoff

## Steps

1. Mark your `AGENT_CLAIMS.md` row `done` (or `blocked` with reason).
2. Replace **Current handoff** in `AGENT_HANDOFF.md` with From/To/Updated, Goal, Done, Files, Next steps, Acceptance criteria, Notes/risks.
3. Optionally move the previous current handoff into **History** (short).
4. Stop at the boundary: do not continue as Cursor unless the user reassigns you.

## Include for Cursor reviews

- How to verify (commands or manual Telegram steps)
- Any security-sensitive behavior changed
